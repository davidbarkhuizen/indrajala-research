# Random permutation machines have no approximation (a corollary of Dixon 1969)

Written 2026-10-24 for the transducers paper's T10 (indrajala-ml's paper workplan, D19) and the
feasibility register's row 17 ([information-flow.md](../protocols/information-flow.md)). The parts
are standard; we claim no novelty for the combination, only that we state it exactly, because the
paper's argument uses it.

**Terms.** A machine here is a deterministic automaton on a finite state set `Q`, `|Q| = q`, its
letters acting on `Q` (outputs play no part). A *congruence* is a partition `π` of `Q` that every
letter respects: `s π r` implies `s·a π r·a` for every letter `a`. Its quotient machine is a
homomorphic image, an *approximation* in Egri-Nagy and Nehaniv's sense (indrajala-ml's
`Mealy.is_congruence`). The machine is *primitive* when it has no congruence but the two trivial
ones (Rystsov and Szykuła 2023: its transition monoid has no nontrivial congruence). A *permutation
machine* is one whose every letter is a permutation of `Q`; `G` is the group its letters generate.

**Lemma 1 (standard).** In a permutation machine, the congruences are exactly the `G`-invariant
partitions of `Q`. If every state is reachable from one state, `G` is transitive, and its invariant
partitions are its block systems; so the machine has an approximation if and only if `G` is
imprimitive.

*Proof.* A partition respected by every letter is respected by every word, so by the monoid the
letters generate; in a finite group of permutations every inverse is a power, so that monoid is `G`.
Conversely a `G`-invariant partition is respected by each letter, an element of `G`. The states
reachable from `s` are its orbit under that monoid, `G`; all of `Q` reachable means `G` transitive,
and a transitive group's invariant partitions are, by definition, its systems of blocks: only the
trivial ones exactly when `G` is primitive. ∎

**Theorem (Dixon 1969, Theorem 2).** The proportion of ordered pairs `(x, y)` of `S_q` generating a
transitive subgroup is `1 - 1/q + O(q^-2)`, and the same holds for a primitive subgroup.

**Corollary 2.** Let a permutation machine have at least two letters that are independent uniformly
random permutations of `Q` (any others, such as an identity letter, arbitrary permutations).

- (a) It is primitive with probability at least `1 - 1/q + O(q^-2)`, and so is it given that every
  state is reachable.
- (b) With exactly two random letters (and any others the identity), given that every state is
  reachable, it is primitive with probability `1 - O(q^-2)`.

*Proof.* Let `H` be the group generated by two of the random letters, `H ≤ G`. (a) If `H` is
primitive then it is transitive, so `G` is, every state is reachable, and every `G`-invariant
partition is `H`-invariant, hence trivial: by Lemma 1 the machine is primitive. Dixon's Theorem 2
gives `P(H primitive) = 1 - 1/q + O(q^-2)`. The event "every state reachable" (call it `R`)
contains "`H` primitive", so `P(primitive | R) >= P(primitive and R) >= P(H primitive)`. (b) Here
`G = H`, `R` is "`H` transitive", and primitive implies transitive, so `P(primitive | R) =
P(H primitive) / P(H transitive)`, whose numerator and denominator are both `1 - 1/q + O(q^-2)`: the
ratio is `1 - O(q^-2)`. ∎

**What it covers, and what not.**

- It covers our `random-perm-<n>-<seed>` machines (`q = n!` states, `n` random permutations and the
  identity: part (a)); `random-perm-3-0` is primitive, as it predicts.
- It does not cover our other random machines (`random-<n>`, `random-q<q>`), whose letters are
  random *transformations*, not permutations. For random transformation monoids we know no such
  theorem. The nearest known result is for a different property, synchronisation (a word sending
  every state to one): Cameron 2011 conjectured that a random automaton with two letters is
  synchronizing with probability `1 - Θ(1/q)`, and Berlinkov proved it (2013, resting on his preprint
  on the highest trees of random mappings); Nicaud 2014 adds that its synchronizing words are short.
  Synchronisation neither implies nor excludes a congruence, so none of this decides primitivity.
  There our statement is an observation: 54 of 55 such machines checked are primitive (row 17).
- The quantifier is over random machines: a designed machine (arithmetic, the algebras, a planted
  machine) can have many approximations; that difference is what T10 tests.
